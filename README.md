# Стрелец A* — чёрная дыра в центре Млечного Пути

Интерактивная модель сверхмассивной чёрной дыры Стрелец A* на **WebGPU**: от спиральной галактики
(10¹¹ GM/c²) до горизонта событий (2 GM/c²) — десять порядков масштаба в одной сцене.
Справа — темы с объяснениями физики простым языком; клик по теме перелетает камерой к явлению.

## Запуск

Нужен Node.js 18+ и браузер с WebGPU (свежие Firefox, Safari, Chrome, Edge).

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build     # сборка в dist/
npm run preview   # просмотр собранной версии
```

## Деплой на Vercel

1. Загрузите репозиторий на GitHub.
2. В Vercel: **Add New → Project → Import** этот репозиторий.
3. Vercel сам определит Vite (настройки уже есть в `vercel.json`): команда сборки `npm run build`,
   папка `dist`. Нажмите **Deploy**. Каждый push в основную ветку будет публиковаться автоматически.

## Управление

- Перетаскивание — вращение камеры, колесо мыши или щипок — масштаб, стрелки и `+`/`−` — с клавиатуры.
- Пробел — пауза. Внизу: скорость времени (от реального времени до ~10 млн лет в секунду), реверс,
  переключатели слоёв: орбиты, подписи, джеты, эффект Доплера, искривление света.

## Что считается и как

Единицы: G = c = M = 1, где M = 4,3 млн масс Солнца. Единица длины GM/c² ≈ 6,35 млн км,
единица времени GM/c³ ≈ 21,2 с. Координаты — относительно чёрной дыры; время модели хранится в float64 на CPU.

| Явление | Модель |
|---|---|
| Искривление света | Каждый пиксель — луч, трассируемый назад по нулевой геодезической Шварцшильда: x″ = −(3/2)·h²·x/r⁵ (метод Рунге–Кутты 4-го порядка, до 400 шагов). Вне сферы радиусом 3000 GM/c² — аналитическое слабое отклонение 4GM/(c²b). |
| Аккреционный диск | Тонкий диск Новикова–Торна: T ∝ r^(−3/4)·(1 − √(6/r))^(1/4), внутренний край на r = 6. Цвет — спектр Планка. Сдвиг частоты g = √(1−3/r)/(1−Ω·L), яркость ∝ g⁴. Текстура движется с кеплеровой скоростью (flow map, чтобы не закручивалась бесконечно). |
| Джеты | Объёмное излучение вдоль оси вращения, релятивистское усиление D^2,5 при β = 0,8. |
| S-звёзды | Реальные орбитальные элементы (Gillessen et al. 2017), уравнение Кеплера, прецессия Шварцшильда Δω = 6πGM/(c²a(1−e²)): для S2 — 12,1′ за оборот. |
| Звезда с планетами | Выдуманная система на орбите 2600 а.е.; показана сфера Хилла r_H = r·(m/3M)^(1/3). |
| Газ | 40 000 частиц в потенциале Пачинского–Вииты Φ = −GM/(r − 2GM/c²) (воспроизводит r_ISCO = 6) с вязким торможением; три потока от звёздных ветров. Compute-шейдер. |
| Приливное разрушение | 16 000 пробных частиц. Звезда задаётся твёрдым шаром на приливном радиусе и интегрируется назад во времени до старта — так воспроизводится «замораживание» разброса энергий ΔE ≈ GMR★/r_t², которое в реальности обеспечивает самогравитация. |
| Галактика | 320 000 звёздных облаков, орбиты в вершинном шейдере: плоская кривая вращения 220 км/с, спиральная волна плотности (Ωp ≈ 26 км/с/кпк), бар; молодые звёзды вспыхивают в гребне волны и гаснут. |

### Честные упрощения

- У настоящего Стрельца A* газа мало, и вместо тонкого яркого диска — горячий разреженный поток (RIAF).
  Тонкий диск, как у квазаров и в «Интерстелларе», показан ради наглядности.
- Мощные джеты у Стрельца A* не обнаружены; в теме «Джеты» они включены для демонстрации.
- Чёрная дыра без вращения (Шварцшильд). Ориентация диска относительно Галактики неизвестна и выбрана условно.
- Радиус разрушаемой звезды увеличен в 3 раза, чтобы её было видно; самогравитации и давления нет.
- Галактика — визуальная модель (звёзды на орбитах с волной плотности), а не N-тело.
- Вблизи центра яркость Галактики приглушена, иначе она засвечивает кадр.

## Структура

```
src/
  main.js            инициализация WebGPU, цикл кадров, ввод, перелёты камеры (GSAP)
  engine/renderer.js все проходы рендера: compute газа, панорама фона, слои спрайтов,
                     трассировка лучей, bloom, тональная компрессия (без зависимости от DOM)
  engine/world.js    сборка состояния кадра: спрайты, орбиты, видимость по масштабу, экспозиция
  engine/camera.js   орбитальная камера с логарифмическим расстоянием
  shaders/           WGSL: lens.js (геодезические), particles.js (галактика, газ, линии, compute)
  sim/               единицы, часы, орбиты, генератор галактики, начальные условия газа и TDE
  ui/                темы (cards.js), панель со шкалой масштаба, приборы, подписи
tools/render.js      headless-рендер кадров через Deno (для проверки шейдеров без браузера)
```

### Headless-проверка (необязательно)

```bash
deno run -A --unstable-webgpu tools/render.js '{"w":640,"h":360,"list":[{"name":"horizon","dist":30,"pitch":0.08}]}'
python3 tools/topng.py 640 360   # кадры появятся в /tmp/shots
```

## Производительность

Разрешение трассировки подстраивается под частоту кадров (50–100% от экрана, плотность пикселей до 1,5).
Если кадры идут медленно — уменьшите окно браузера или отойдите камерой от горизонта.

- Gillessen S. et al. (2017), ApJ 837, 30 — орбиты S-звёзд.
- Event Horizon Telescope Collaboration (2022), ApJL 930, L12 — снимок Стрельца A*.
